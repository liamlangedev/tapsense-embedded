🔌 Single FSR Voltage Divider Wiring

📋 What You Need

• ESP32 MiniKit
• 1× FSR sensor pad (any zone, Pin 1 + Pin 2)
• 1× 2kΩ resistor (Red-Black-Red)
• 1× 8kΩ resistor (Gray-Black-Red)
• 5× jumper wires

🔧 Step-by-Step Wiring

Step 1: Connect 3.3V from ESP32 → FSR Pin 1 (far left)
Step 2: Connect FSR Pin 2 (second from left) → Breadboard Row A
Step 3: Place 2kΩ from Row A → Row B
Step 4: Place 8kΩ from Row B → GND rail
Step 5: Jumper from Row A → ESP32 GPIO 32
Step 6: Connect GND from ESP32 → Breadboard GND rail
✅ Expected Readings (no touch):
IO32: ~3200-3400 (voltage divider idle)

When pressed: drops to ~1000-2500 depending on pressure

📤 Upload Code

1. Open /tmp/single_pad_test.ino in Arduino IDE
2. Select Tools → Board → ESP32 Dev Module
3. Select Tools → Port → /dev/ttyACM0
4. Click Upload
5. Open Serial Monitor (115200 baud)
